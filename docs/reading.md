# 使用指南

## 导入和翻译

1. 在书架点击「创建小说」，输入书名和可选作者。
2. 点击「添加章节」，填写标题并粘贴日文；预览显示前八个自然段。每章最多 200000 字。
3. 保存后即可阅读和朗读原文。需要中文时，点击「手动输入译文」录入、在对应段落旁点击「翻译此段」，或用「整章翻译」批量安排任务。
4. 一次任务仍只翻译一段；整章翻译由多个独立任务组成，同章顺序执行。总进度显示完成／总段数，失败只影响该段，其他段落继续处理。

整章翻译跳过已有译文与人工译文，重复点击运行中的批次会复用原批次。可用「停止整章翻译」停止所有剩余任务；失败、停止或服务重启后，使用「补齐未完成译文」重新安排缺失段落，已成功内容不会重复调用模型。

自然段以换行为基础。空行仍保存在原始文本中；阅读区展示非空文本单元。超长段落内部拆分成多个对照单元，原文字符和次序不变。

「重新翻译此段」明确重生成该段；旧译文在成功发布前保持可读。修改译文后标记「已人工校对」，自动任务不会覆盖它。翻译按钮在对照、中文和仅日文模式下都可使用。

## 章节排序与删除

目录中每章右侧提供上移、下移和删除按钮，手机上先展开章节目录。顺序保存到 SQLite，刷新后保留，并用于下一章导航；排序不会改变原文、译文、音频或阅读位置。

删除章节需确认，会删除该章原文、译文、历史、任务与对应阅读位置，并停止在途任务。其他章节和共用音频保留；无引用音频以后可通过缓存清理移除。删除当前章后打开相邻章节，删除最后一章后返回添加章节界面。删除无法在界面撤销，需要时先备份数据。

排序带有当前目录快照，删除校验原文版本；另一页面修改目录或原文时会提示冲突，刷新后重试。

## 升级提示

从旧数据库升级时，迁移可能把旧的未完成翻译任务标记为「已作废」，不能继续或重试；已成功写入的译文和语音任务保留。版本差异、备份和回滚步骤见[升级与迁移](upgrading.md)。

## 手动输入与无译文使用

- 章节顶部的「手动输入译文」在对照、仅日文、仅中文模式下均可使用。对照日文段落输入或粘贴中文，点击「保存已填写译文」一次保存。
- 可以只填写部分段落。空白输入不作修改：尚无译文的段落保持为空，已有译文不会被空白输入清除。
- 对照或中文模式下，也可使用单段「填写译文」与「校对译文」。手工保存只写入 SQLite，不调用翻译模型。
- 批量保存同时检查章节与各段版本；若别的页面或后台任务修改了任一目标，整批拒绝保存，输入草稿仍留在弹窗中，避免一部分被保存、一部分丢失。
- 翻译 API 未配置、认证失败或暂时不可用时，原文阅读、章节切换、字号/主题、术语表、手工译文、阅读进度、日语朗读和读音修改均可独立使用。新语音仍需要可用的 TTS 服务；已经缓存的音频不需要再次调用模型。
- 手工译文保存不会修改日文原文、朗读文本、已有音频和播放位置。自动生成会保留人工译文，只补齐其余段落。

## 术语和修改

在目录底部打开「人名与术语表」，保存原词、固定中文译名及可选读音。模型使用术语表翻译；它不会直接重写已生成的译文或语音。

「校对译文」允许手工保存翻译。编辑期间如果另一页面或任务已保存新版本，将提示版本冲突，不静默覆盖。关闭含未保存内容的编辑框会提示确认。

「编辑原文」实际改变文字时创建新原文版本、重新建立分段与音频关联，旧原文和旧译文快照仍在数据库中。相同原文重复保存不使结果失效；修改标题也不触发重新翻译。当前版本不提供历史版本恢复界面，恢复可通过备份或后续工具处理。

## 朗读

- 点击段落「朗读」：缺失音频时按需生成。首次异步加载后，浏览器可能要求再次点击播放器才能播放。
- 点击「准备整章语音」：补齐章节内缺失音频。已缓存的相同文本与声音不会再次调用模型。
- 播放器默认 **1.0×（原速）**，也支持手动选择 0.65–2 倍速、上一片段、下一片段、暂停、进度拖动和当前片段循环。重新打开页面恢复默认原速。
- 连播时按音频片段推进，预取后续两个片段；长段落可能由多个片段组成，高亮对应文字段落。
- 关闭「跟随」后，播放不再自动滚动正文。
- 「调整读音」可用假名替换歧义汉字，保存后只使该段语音失效，原文和中文译文保持不变。
- 「重新生成现有朗读」使用已保存的朗读文本，显式重新调用模型；不会自动保存尚未提交的输入。

在设置中展开「高级设置」，可调整「语音生成并发量」，默认 10，范围 1–32。保存立即影响后续生成，并在重启后保留；调低上限时当前正在生成的片段会继续完成。此设置控制生成请求数量，不改变播放速度 1.0。配置优先级和并发语义见[服务配置](configuration.md#并发重试与音频缓存)。

## 阅读位置与任务

阅读位置以段落记录；播放期间约每 5 秒及暂停时保存当前片段、播放秒数。打开同一本小说会恢复上次章节和位置。浏览器 localStorage 只保存主题、字号、显示模式等界面偏好。

写入失败时显示提示并保留待保存位置，避免无提示丢失。多页面同时写入发生冲突时需刷新后继续。

关闭网页不取消后台任务。「停止」会尝试中断当前网络请求，语音任务同时停止后续调度，已成功结果保留。服务重启后不会自动恢复付费调用，未作废的新任务可手动点击「继续 / 重试」。原文、术语或模型配置已变更的任务应重新创建。

## 清理缓存

设置中的「清理未使用音频」只删除没有被任何章节片段引用的音频资源；有生成任务运行时拒绝清理。已关联的音频保留。清理后再次需要旧内容时可能重新调用 TTS。

## 隐私与限制

启用自动翻译或语音时，相关文本会发送到所配置的第三方服务；数据、隐私和费用边界见[运维、限制与故障排查](operations.md)。自动播放、FFmpeg、浏览器支持等限制也在同一文档中说明。
