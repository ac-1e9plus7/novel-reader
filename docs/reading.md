# 使用指南

## 导入和翻译

1. 在书架点击「创建小说」，输入书名和可选作者。
2. 点击「添加章节」，填写标题并粘贴日文；预览显示前八个自然段。每章最多 200000 字。
3. 保存后点击「生成翻译」。译文按批出现，处理记录显示完成批数。
4. 点击记录查看失败原因、每次尝试耗时和服务返回用量。「继续 / 重试」只处理未成功部分。

自然段以换行为基础。空行仍保存在原始文本中；阅读区展示非空文本单元。超长段落内部拆分成多个对照单元，原文字符和次序不变。

「生成翻译」只补齐缺失译文。单段「重新翻译」明确重生成该段；旧译文在成功发布前保持可读。修改译文后标记「已人工校对」，自动任务不会覆盖它。

## 术语和修改

在目录底部打开「人名与术语表」，保存原词、固定中文译名及可选读音。模型使用术语表翻译；它不会直接重写已生成的译文或语音。

「校对译文」允许手工保存翻译。编辑期间如果另一页面或任务已保存新版本，将提示版本冲突，不静默覆盖。关闭含未保存内容的编辑框会提示确认。

「编辑原文」实际改变文字时创建新原文版本、重新建立分段与音频关联，旧原文和旧译文快照仍在数据库中。相同原文重复保存不使结果失效；修改标题也不触发重新翻译。当前版本不提供历史版本恢复界面，恢复可通过备份或后续工具处理。

## 朗读

- 点击段落「朗读」：缺失音频时按需生成。首次异步加载后，浏览器可能要求再次点击播放器才能播放。
- 点击「准备整章语音」：补齐章节内缺失音频。已缓存的相同文本与声音不会再次调用模型。
- 播放器支持上一片段、下一片段、暂停、进度拖动、0.65–2 倍速和当前片段循环。
- 连播时按音频片段推进，预取后续两个片段；长段落可能由多个片段组成，高亮对应文字段落。
- 关闭「跟随」后，播放不再自动滚动正文。
- 「调整读音」可用假名替换歧义汉字，保存后只使该段语音失效，原文和中文译文保持不变。
- 「重新生成现有朗读」使用已保存的朗读文本，显式重新调用模型；不会自动保存尚未提交的输入。

## 阅读位置与任务

阅读位置以段落记录；播放期间约每 5 秒及暂停时保存当前片段、播放秒数。打开同一本小说会恢复上次章节和位置。浏览器 localStorage 只保存主题、字号、显示模式等界面偏好。

写入失败时显示提示并保留待保存位置，避免无提示丢失。多页面同时写入发生冲突时需刷新后继续。

关闭网页不取消后台任务。「停止」会取消后续调度、尝试中断当前网络请求，已成功结果保留。服务重启后不会自动恢复付费调用，请手动点击「继续 / 重试」。原文、术语或模型配置已变更的旧任务应重新创建。

## 清理缓存

设置中的「清理未使用音频」只删除未被当前章节引用的音频资源；有生成任务运行时拒绝清理。已关联的音频保留。清理后再次需要旧内容时可能重新调用 TTS。
