# 实现与维护约束

本文是实现不变量，不是流程教程。请求流和组件关系见[架构与数据流](architecture.md)，HTTP 契约见[HTTP API](api.md)。

## 原文和版本

1. 用户粘贴的 raw 原样保存。分段保持原文字节对应的 Unicode 字符次序，不用模型生成的日文替换原文。
2. 原文实际变化递增章节 revision、保存快照、重建分段；相同 raw 重复保存不得删除已有译文或音频。
3. 译文和朗读文本各有独立 revision。保存时校验版本，过期写入返回 409。
4. 模型结果发布前再次检查章节版本、术语表版本和目标译文版本；人工译文不可覆盖。单段结果和任务分项在同一事务中发布。
5. 更新朗读文本只替换该段的 clips，不修改原文及译文。旧共享音频在无引用并显式清理前仍可读取。
6. 译文是可选数据。阅读、语音、术语与进度操作不能检查“整章已翻译”作为前置条件，也不能为使用这些功能隐式调用翻译服务。
7. 章节批量手工译文在同一事务保存：校验章节 revision、段落归属、唯一 ID 和各译文 revision。只改提交的段落，不改原文、音频及未提交译文；任何冲突全部回滚。浏览器跳过空白输入，不把空白视作删除请求。

## 任务

- SQLite 保存 jobs、job_items 和每次生成尝试；前端不是任务真相来源。
- 翻译任务必须显式选择恰好一个段落；模型调用只包含一个翻译目标，上下文只供参考。整章批次仅负责原子建立多个独立单段任务，不能把多个目标合并到一次模型请求。
- 版本 2 迁移一次性作废所有旧未完成翻译任务，保留已保存译文和成功分项；invalidated 任务不能重试，也不能在重启恢复时改回 queued/interrupted。
- 同章同一段最多一个 queued/running 翻译任务，重复请求复用它；同章多个段落可排队，但最多一个翻译任务同时运行。批次重复提交复用活动批次，补齐时跳过成功和人工译文。
- 音频整章任务内部并发执行片段，跨章节共用动态 TTS 上限。调整并发不得替换仍有持有者的信号量、泄漏名额、取消已有录音或改变缓存键。取消必须释放等待名额的工作协程。
- 成功分项与业务结果在一个事务发布；崩溃后不可让已提交内容再次生成。
- 重试只重置未成功项。服务启动将 queued/running 标记 interrupted，不自动发起付费模型调用。
- 取消保留成功项并传播 context；无法承诺取消远端计费。
- 原文改变使旧任务失效。术语改变使旧翻译任务失效。模型配置改变后，旧任务不能以新配置悄悄续跑。
- 提示词语义变化必须递增 `backend/internal/app/providers.go` 中的翻译或语音提示词版本常量。不得让旧缓存键复用新提示词，也不得因翻译提示词变化使全部语音缓存失效。
- HTTP 429/5xx 最多两个重试；不叠加无限内容纠错循环。外部请求不是 exactly-once；远端成功、本地提交前崩溃仍可能导致重试收费。

## SQLite 与文件

- 同一数据目录仅允许一个进程，用跨平台文件锁约束；SQLite WAL、外键开启、连接池仅一连接。
- `Store.mu` 串行协调需要一致性的多步读写。使用显式短事务，不在事务内等待 LLM、TTS 或 FFmpeg。
- 新录音使用独立随机 asset ID；文件先写临时路径再原子发布，随后插入数据库资源。不能把旧元数据与新文件混配。
- FLAC 转码后解码并逐样本比较，成功更新当前资产表示后再删除 WAV。生成 ID 不复用，旧压缩结果不可覆盖新录音。
- 音频读取在锁内取得完整字节快照，删除或压缩不影响正在返回的 HTTP 响应。
- 缓存键包含 provider、endpoint、模型、声音、朗读文本和语音提示词版本；翻译提示词版本独立，不让翻译调整引发全部音频重新计费。
- 同键合成共享锁，等待者也计入引用计数，不能在仍有等待者时替换锁。
- 缓存清理在没有运行任务时执行，只删除没有 clip 引用的资产。数据库与文件系统不能跨系统事务，需允许崩溃残留的孤立文件后续清理。
- 章节排序校验完整旧目录快照及章节归属，事务内更新连续 position，不修改内容 revision。删除先事务删除本章依赖，再取消在途请求；晚到结果不得重建已删章节，共用音频资产不随章节删除。

## 浏览器与密钥

- 模型密钥只放后端环境，公开配置明确列字段，错误消息不回显远端正文、请求头或密钥。
- 原文、模型文本均视为数据，React 文本节点渲染，禁止未净化的 HTML 注入。
- 默认本机监听，Host 和写请求标识用于基础防护，不构成用户认证。开放网络监听需额外权限隔离和 TLS。
- 阅读进度以 SQLite 为准，前端串行保存并检查 revision；冲突必须可见，不能盲目覆盖其他页面位置。
- 主题、字号等显示偏好可放 localStorage；不能把它当持久化阅读位置的唯一存储。
- 自动播放受浏览器策略限制，等待异步音频后应允许用户点击继续。

## 验证

所有任务、版本、语音或存储变更必须运行相应回归测试。涉及多个模块时运行后端全量和浏览器流程。真实模型的翻译准确度、读音自然度、具体供应商兼容性不能由假模型测试证明；验收方法见[测试策略](testing.md)和[真实验证记录](verification.md)。
